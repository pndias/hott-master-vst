# Screenshots

This directory holds screenshots used in the README.

## How to add screenshots

1. Build the plugin (`./build-macos.sh` or `build-windows.bat`)
2. Load `Hott Master.vst3` in your DAW
3. Capture the following screenshots and save them here:

| Filename | Description |
|----------|-------------|
| `hott-master-logo.png` | Logo icon (120×120 px, transparent background) |
| `screenshot-full-ui.png` | Full plugin window in DAW |
| `screenshot-soothe.png` | Resonance Suppressor section close-up |
| `screenshot-eq.png` | Linear Phase EQ section close-up |
| `screenshot-comp.png` | Bus Compressor section close-up |
| `screenshot-clipper.png` | Soft Clipper section close-up |
| `screenshot-limiter.png` | True Peak Limiter section close-up |
| `screenshot-meters.png` | GR meters (Compressor + Limiter) |
| `screenshot-knob-detail.png` | Close-up of a single knob |

Recommended: capture at 2× resolution for Retina/HiDPI displays, then reference at half size in the README.
